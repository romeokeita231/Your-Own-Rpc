# 推荐答案

## 你的RPC框架采用了什么协议，为什么要自定义协议？

为了提高请求性能、减少数据传输，我自主设计了一套 RPC 协议，包括自定义消息结构和网络传输方式。

我在设计自定义协议时，借鉴了 Dubbo 的协议。

**1）自定义消息结构：** 设计的核心理念是 "用最少的空间传递需要的信息"，所以我使用字节数组来存储拼接消息。消息内容分为消息头 + 消息体，消息头里面的内容包括了魔数、版本号、序列化器、消息类型、状态、请求 id、消息体长度信息。

**2）网络传输方式：** 我选择使用 TCP 协议完成网络传输，相比于 HTTP 协议的性能更高。

因为 HTTP 头信息是比较大的，会影响传输性能。除了这点外，HTTP 本身属于无状态协议，这意味着每个 HTTP 请求都是独立的，每次请求/响应都要重新建立和关闭连接，也会影响性能。

**为什么要自定义协议？理由如下：**

1. 更高的性能。自定义协议允许我根据应用的特定需求来设计数据格式和通信机制，从而减少不必要的数据传输，降低网络延迟，提高数据处理速度。

2. 灵活性和扩展性。通过自定义协议，我设计了包含版本信息的协议头，可以支持向后兼容和协议升级。

3. 安全性。比如在消息头中引入了魔数进行安全校验。

# 练习题

## 1. 在设计RPC自定义协议时，以下哪项不是消息头中包含的内容？()

- A. 消息体的具体数据内容
- B. 魔数
- C. 请求id
- D. 序列化器类型



## 2. 关于RPC框架选择TCP而非HTTP协议的原因，以下说法错误的是？()

- A. TCP协议相比HTTP具有更好的性能
- B. HTTP协议每次请求都需要重新建立连接
- C. HTTP协议的消息头比TCP协议更小
- D. HTTP是无状态协议



## 3. 以下哪项不是自定义RPC协议的优势？()

- A. 可以实现更高的性能
- B. 能够支持协议版本升级
- C. 可以使用更简单的调试工具
- D. 可以提供更好的安全性



## 4. 在RPC协议设计中引入魔数的主要目的是？()

- A. 提高序列化效率
- B. 进行安全校验
- C. 减少网络延迟
- D. 支持协议版本控制



## 5. 关于RPC协议的消息结构设计原则，以下说法最准确的是？()

- A. 应该尽可能包含丰富的信息
- B. 应该使用文本格式提高可读性
- C. 应该用最少的空间传递需要的信息
- D. 应该优先考虑开发便利性

# 答案解析

**1. 正确答案：A**

官方解析：根据官方题解，消息头包含魔数、版本号、序列化器、消息类型、状态、请求id、消息体长度信息，而消息体的具体数据内容属于消息体部分，不属于消息头。

**知识点：** RPC协议设计、消息结构

**2. 正确答案：C**

官方解析：官方题解明确指出HTTP头信息比较大，会影响传输性能，因此选项C说HTTP消息头更小是错误的。其他选项都符合题解描述。

**知识点：** 网络传输协议、性能优化

**3. 正确答案：C**

官方解析：根据官方题解，自定义协议的优势包括性能、灵活性和扩展性、安全性，但并未提到调试工具方面的优势，反而自定义协议可能增加调试难度。

**知识点：** 系统设计、RPC协议优势

**4. 正确答案：B**

官方解析：官方题解明确指出在消息头中引入魔数是为了进行安全校验，这是常见的安全防护手段。

**知识点：** 校验机制、协议安全

**5. 正确答案：C**

官方解析：官方题解明确提到设计的核心理念是"用最少的空间传递需要的信息"，这是自定义协议的重要优化方向。

**知识点：** 协议设计原则、性能优化
